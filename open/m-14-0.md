## The ask

Make the tag `vc-x1`'s, so no session has to remember it.

- `cycle --land <target>` tags the commit the target moves to `v<version>`, the version read by
  the `[version]` table's `file` and `pattern`, by default.
- `--no-tag` skips it, for a Land the user says is not worth a tag.
- `--push`, and `vc-x1 push` of the target, publish the tag with the target.
- A tag already at another commit is refused, naming both commits, since a moved tag breaks a
  dependent that pinned it.

## Ours

The hand step is `jj tag set v<version> -r main` and `jj git push --tag v<version>`, in our
`custom.md`, and it goes once `cycle --land` does it. Our Todo for proposing the step to the set,
`Propose a tag step for every Land`, becomes this request.
