# m-12-0 tag versions so io-uring-x1 can pin a git dependency

io-uring-x1 now carries NOPs to its io_uring over zc-ring-x1's spsc queues, the default `Ring`,
v3, in its cycle `feat: issue IORING_OP_NOP via io_uring primitives`, landed at

## The ask

Tag zc-ring-x1's versions, so io-uring-x1 can depend on it by git at a tag.

- Today the dependency is a path, `zc-ring-x1 = { path = "../zc-ring-x1" }`, so a build takes
  whatever the sibling checkout holds, and a clone without it does not build.
- A git dependency at a commit works now, `main@origin` being `e705b50d`, the commit io-uring-x1
  was built against, but a raw hash says nothing of the version.
- A tag per landed version, `v0.19.5` at `e705b50d` to start, lets a dependent write
  `tag = "v0.19.5"` and see what it pinned.
